## 七、命名约定（写进 DoD）

1. **事件一律过去时**：`QuestionPosted`、`AnswerAccepted`，不用 `PostQuestion` 当事件名。
2. **命令才用动词原形**：`PostQuestion`、`AcceptAnswer`（类名用动名词形式如 `PostQuestionCommand`）。
3. **数据库表名按上下文加前缀**：`id_` / `qa_` / `rep_` / `dis_`，**禁止跨前缀 JOIN 与外键**（ADR-001）。
4. **跨上下文只能依赖对方的 `*-api` 模块或订阅其事件**，不得直接引用对方的领域类。
5. 代码新增领域概念时，**先改本表再写代码**；PR 评审时若发现术语与表不一致，按 must 处理。
