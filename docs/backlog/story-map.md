## 读法

- **横轴（Backbone）**：用户从左到右的活动顺序，即一个人使用 CampusOverflow 的完整旅程；
- **纵轴（Walking Skeleton → Body）**：同一活动内，**越靠上价值越高、越早交付**；
- **切片线**：横线划过的是"某个版本最少要交付什么"，而不是"我们想做多少"；
- 🔍 标记 = 有真实访谈证据支撑（来源 `docs/research/interview-R3.md`）；
- ⬚ 虚线 = 建议新增、尚未进入 PO Backlog（见 `co-to-us-mapping.md` §四）。

## 三、Walking Skeleton（Sprint 1 切片）

```
US-001 注册 ─→ US-002 登录 ─→ US-005 发布问题 ─→ US-007 加标签
                                                      │
                    US-003 浏览列表 ←─────────────────┘
                          │
                    US-004 查看详情 ─→ US-008 提交回答
```

**合计 16 SP**（3+2+3+2+2+2+2）。这条链走完，用户能"注册 → 提问 → 被浏览 → 被回答 → 看到回答"，是一条端到端可演示的最薄切片。
**砍掉任何一张都会断链**：没有 US-007 发布不合规；没有 US-008 则问题无人回答，演示停在"已发布"。
